# 차탄 맘 공용 DB 완성본

Vercel + Neon Postgres용 Next.js 프로젝트입니다.

기능: 공용 회원가입/로그인, 영어 아이디, 아이디/닉네임 중복 검사, 다른 기기 로그인, 비밀번호 보이기/숨기기, 닉네임/비밀번호 변경, 계정 삭제, 게시물/공지 글·이미지 업로드, 작성자 삭제, 관리자 삭제, 관리자 jiwooeo 👑, 부관리자 요청/승인/삭제, 공지 권한, 새 게시물/공지 파란 점, 모바일 대응.

Neon 환경변수 POSTGRES_URL / DATABASE_URL / NEON_DATABASE_URL 중 하나를 사용합니다. 기존 Vercel 프로젝트에 Neon을 연결했다면 환경변수가 이미 있을 가능성이 높습니다.

관리자 아이디는 정확히 jiwooeo 입니다.

이미지는 작은 팬클럽용으로 1.5MB 이하 Base64를 DB에 저장합니다.
